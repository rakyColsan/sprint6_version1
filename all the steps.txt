1-After installing Git, you should configure the global settings that apply to all repositories for your user account.
For example:
git config --global user.name "Rami Alkubaty"
git config --global user.email "rami.alkubaty@iu.org"
git config --global init.defaultBranch main
git config --global core.editor "code --wait"

# Alternative editors:
# git config --global core.editor nano
# git config --global core.editor vim

2-To check your global Git configuration:
git config --global --list

3-git init: creates the hidden .git directory inside the current folder
 Powershell: dir -Force
4-git status: It shows the current state of your working directory and staging area.
5-The staging area is basically a temporary preparation area for your next commit.
  git add 
6-Commit: git commit -m "message"; git log (hit (q))  
7-Delete:
         1-Untracked / not staged yet:
         1.1-Delete manually
         1.2-rm filename
         1.3-git clean -f filename
         2-Staged:
           Bring the to unstaged phase and then:
           git restore --staged file.txt  
           rm filename 
         3-Commited:
          git rm file.txt
          git commit -m "Remove file.txt"  
8-Create a branch:
  git switch -c new_feature

9-Back to the main branch: 
  git switch main
10-Merge changes:
   git merge new_feature  
11-
   11.1 create an empty repository on github
   11.2 Connect local repository to a GitHub repository and push it:
        git remote add origin https://github.com/rakyColsan/sprint6_version1.git 
   11.3 push it:
        git push -u origin main
12-Working in a team (first pull we use clone):
   12.1 to colone github repository:
   git clone https://github.com/rakyColsan/sprint6_version1 
   12.2 Make changes:
        git add .
        git commit -m "message
   12.3 Push your changes:
        git push
